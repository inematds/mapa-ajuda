Escolha um cartão. Cada um abre o caminho com os passos, em ordem.

Use este modelo no seu site

Esta página é um modelo aberto. O visual e a lógica ficam no index.html; o conteúdo inteiro fica num arquivo de configuração. Troque a configuração e a página vira o mapa de ajuda do seu negócio.

1. Copie o modelo

Baixe o repositório ou use como template no GitHub. Não precisa de build nem de servidor.

2. Escreva os caminhos

Edite o config.js: um problema por cartão, e para cada um os passos, perguntas de sim ou não e links.
